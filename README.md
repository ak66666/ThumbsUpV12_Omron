# ThumbsUp! v12 RP2040-based ProMicor 3x12 keyboard for Omron and mouse switches.
                           
Steno keyboard (number key instead of a bar)
2-key Thumb Cluster

* RP2040 ProMicro.
* TRS (3-wire) audio cable to connect the halves.
* USB-C connectors.
